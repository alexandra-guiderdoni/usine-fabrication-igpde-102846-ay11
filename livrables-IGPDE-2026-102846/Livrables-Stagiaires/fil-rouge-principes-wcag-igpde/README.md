# Fil rouge : les principes WCAG

Ce dossier réunit les supports du fil rouge de la formation : les 4 principes WCAG (percevoir, utiliser, comprendre, compatible), introduits au module 1 et repris dans les ateliers Word, web et réseaux sociaux.

## Quel document, à quel moment

- `fiche-stagiaire-principes-wcag.pdf` : à distribuer à la slide 29 (« 6 profils, 4 questions - votre boussole WCAG ») ; les stagiaires la gardent ouverte ou imprimée pendant les ateliers.
- `cartes-criteres-wcag-2-2-a-imprimer.pdf` : les critères WCAG 2.2 sous forme de cartes, en français, 6 par page, à imprimer.

## Provenance

- La fiche stagiaire est générée par l'usine de la formation (`make pdf`, source dans `wcag/`). Ne pas la modifier ici : la génération suivante écraserait la modification.
- Les cartes sont une ressource externe sous licence CC BY-SA 4.0 : auteur, sources et licence dans `CREDITS.md`.
- `assets/` contient le bandeau IGPDE utilisé pour générer les PDF du pack.
