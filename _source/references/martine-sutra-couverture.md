# Couverture pédagogique issue du support Martine Sutra

## Statut et limite

Ce fichier définit des codes locaux de couverture pour la refonte du TP Sami.
Ils reprennent uniquement les thèmes énumérés au paragraphe 16 du PRD
`notes/prd-refonte-partie-II-tp-sami.md`.

Le support pédagogique externe n'est pas présent dans le clone. Cette liste ne
prétend donc ni le reproduire, ni en transcrire le plan ou les formulations. Les
codes servent à vérifier que les thèmes retenus dans le PRD restent traçables
depuis la future matrice canonique.

## Codes de couverture

- `MS-01` : contrastes ;
- `MS-02` : images ;
- `MS-03` : métadonnées ;
- `MS-04` : langues ;
- `MS-05` : styles ;
- `MS-06` : titres ;
- `MS-07` : navigation ;
- `MS-08` : sommaire ;
- `MS-09` : listes ;
- `MS-10` : majuscules ;
- `MS-11` : acronymes ;
- `MS-12` : marques de mise en forme ;
- `MS-13` : liens ;
- `MS-14` : lisibilité ;
- `MS-15` : vérificateurs ;
- `MS-16` : export PDF ;
- `MS-17` : tableaux ;
- `MS-18` : contrôle après export.

## Règle d'utilisation

À partir de T02, chaque contrôle pertinent de
`_source/exercice-sami-matrice.yml` référence un ou plusieurs de ces codes. Un
code atteste seulement la couverture d'un thème : il ne crée pas un critère
supplémentaire, ne fixe pas son niveau `P`, `C` ou `S` et ne remplace ni le PRD
ni la matrice.

Toute évolution de cette liste exige une source pédagogique disponible dans le
dépôt ou une décision humaine consignée ; elle ne peut pas être déduite du seul
souvenir du support externe.
