# Checklist Anticiper / Rédiger / Publier

## Anticiper
- [ ] Média prévu : image, audio, vidéo ou carrousel.
- [ ] Alternative prévue : alt text, transcription, sous-titres ou version texte.
- [ ] Visuel inclusif et représentatif, sans stéréotype.
- [ ] Version complète prévue si le visuel est dense.
- [ ] Police lisible et contraste suffisant pour mobile.
- [ ] Le texte sur image n'est pas le seul accès à l'information.

## Rédiger
- [ ] Informations essentielles présentes dans le texte du post.
- [ ] Paragraphes courts.
- [ ] Texte natif, sans faux gras Unicode ni police fantaisie.
- [ ] Émojis sobres, placés en fin de message, avec sens vérifié.
- [ ] Hashtags en CamelCase, courts et regroupés en fin de post.
- [ ] Langage inclusif clair : épicène, double flexion ou formulation comprise par le public.

## Publier
- [ ] Alt text clair et unique pour chaque image informative.
- [ ] Infographie ou carrousel : chiffres et messages clés repris en texte.
- [ ] Audio : transcription écrite jointe ou lien visible.
- [ ] Vidéo : sous-titres relus, transcription si nécessaire.
- [ ] QR code jamais seul : lien visible, libellé explicite, taille et contraste.
- [ ] Relire le post sans les images, les émojis et les effets visuels.
