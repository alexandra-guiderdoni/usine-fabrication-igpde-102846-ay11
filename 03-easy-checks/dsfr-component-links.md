## Téléchargement de fichier

Le composant **Téléchargement de fichier** est déprécié. Ne pas utiliser son ancien code.

Pour la grille, utiliser une variation de téléchargement via **Lien**, **Carte** ou **Tuile** :

- Lien - code : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/lien/code-du-lien
- Lien - accessibilité : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/lien/accessibilite-du-lien
- Carte - code : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/carte/code-de-la-carte
- Carte - accessibilité : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/carte/accessibilite-de-la-carte
- Tuile - code : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/tuile/code-de-la-tuile
- Tuile - accessibilité : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/tuile/accessibilite-de-la-tuile

## Messages d'erreur

Il n'y a pas un composant autonome unique "message d'erreur" à utiliser seul pour nos besoins. Les messages d'erreur doivent être implémentés via :

- Formulaire : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/formulaire/code-du-formulaire et https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/formulaire/accessibilite-du-formulaire
- Champ de saisie : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/champ-de-saisie/code-du-champ-de-saisie et https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/champ-de-saisie/accessibilite-du-champ-de-saisie
- Alerte : https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/alerte/code-de-l-alerte et https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/alerte/accessibilite-de-l-alerte
