# Site d'exercice des TP

Ce dossier contient la source canonique du site d'exercice remis aux stagiaires : les versions inaccessible, d'aide à la correction et accessible des travaux pratiques web, ainsi que leurs ressources.

Le site publié est une copie de ce dossier dans le dépôt `tp-fabrication-igpde-102846-ay11`, servie par GitHub Pages. Ne modifiez jamais directement ce dépôt ni ses clones locaux : la publication suivante écraserait ces changements.

Pour modifier le site :

1. Éditez les fichiers de ce dossier.
2. Lancez `make verifier` à la racine de l'usine.
3. Lancez `make publier-site` à la racine de l'usine.

Ce README est une documentation interne : `make publier-site` n'envoie pas les fichiers Markdown de `docs/` vers le site public.
