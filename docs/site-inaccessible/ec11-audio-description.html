#11 Démonstration vidéo

CAPTCHA : le retour au Moyen Âge

Cette page présente une vidéo de sensibilisation aux difficultés posées par les CAPTCHA visuels.

Question d'audit

Avant de regarder l'aide, listez les informations qui restent perdues sans l'image, sans le son ou sans alternative textuelle.

Informations de publication

La vidéo est prévue pour accompagner une page de sensibilisation aux obstacles rencontrés avec les CAPTCHA visuels.

Le contenu est compréhensible pour une personne qui voit l'image et entend le son, mais aucune alternative n'est proposée à proximité du lecteur.
