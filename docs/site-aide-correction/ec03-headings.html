#3 Guide du RGAA

Aide à la correction

Afficher le plan de titres avec HeadingsMap, puis le comparer au plan visuel. Chercher les titres visibles qui n'apparaissent pas dans le plan, et les titres du plan qui ne correspondent pas à une vraie rubrique.

Le plan technique peut être absent, pollué ou mal interprété ; la navigation par titres devient inefficace. Le h1 interne est volontairement très incohérent : il se discute dans le plan de titres, mais ne doit pas masquer les erreurs de sémantique.

Indices ciblés par cas :

  • Faux titres : « Comprendre le RGAA », « Avant de publier », « Ressources pour les contributeurs » et « À retenir pour l'équipe » sont visuellement présentés comme titres, mais codés avec des paragraphes.
  • Titre détourné : « Publication urgente avant vendredi » est codé en h3 alors qu'il s'agit d'une mise en valeur éditoriale.
  • Incohérence de plan : « Repères déjà présents » revient au niveau h1 au milieu du contenu, alors qu'il dépend visuellement de la rubrique Ressources.
  • Bonnes pratiques déjà présentes : les accès rapides, le fil d'Ariane et les zones principales ne compensent pas les titres mal structurés.

Identifier les vrais titres, vérifier leur sémantique, repérer les titres utilisés pour la présentation et qualifier les sauts de niveau avec nuance.

Messages de correction ciblés :

  • Faux titres : remplacer chaque paragraphe stylé par un vrai titre de rubrique adapté au niveau attendu, ou retirer le style de titre si le texte n'ouvre pas une section.
  • Titre détourné : remplacer le h3 de mise en valeur par un paragraphe, éventuellement avec strong et une classe CSS.
  • Niveau incohérent : redescendre « Repères déjà présents » au niveau attendu dans la rubrique Ressources.

Guide du RGAA

Comprendre le RGAA

Le RGAA aide les équipes à vérifier qu'un service numérique reste utilisable par le plus grand nombre. Les contributeurs peuvent l'utiliser pour préparer une publication avant sa mise en ligne.

Avant de publier

Cette page rassemble les premiers repères à contrôler sur une ressource ministérielle. Elle sert aussi à orienter les demandes vers les bons interlocuteurs.

Publication urgente avant vendredi

La ressource de référence doit être relue par l'équipe publication. Les remarques sont centralisées dans le tableau de suivi partagé.

Les équipes éditoriales signalent les points bloquants avant l'envoi en validation. Les corrections mineures peuvent être intégrées dans la prochaine mise à jour.

Ressources

Ressources pour les contributeurs

Guides pratiques

Les guides pratiques décrivent les contrôles à réaliser avant publication. Ils présentent les points à vérifier sur les images, les formulaires et les contenus multimédias.

Repères déjà présents

La page propose des accès rapides, un fil d'Ariane, une navigation principale et un pied de page. Ces repères aident les utilisateurs à comprendre où ils se trouvent dans le site.

À retenir pour l'équipe

Les vérifications doivent rester simples à partager. Le responsable de publication conserve la trace des corrections effectuées avant la mise en ligne.
