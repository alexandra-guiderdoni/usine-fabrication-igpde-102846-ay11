3. Guide du RGAA

Aide à la correction

Afficher le plan de titres avec HeadingsMap, puis le comparer au plan visuel. Chercher les titres visibles qui n'apparaissent pas dans le plan, et les titres du plan qui ne correspondent pas à une vraie rubrique.

Le plan technique peut être absent, pollué ou mal interprété ; la navigation par titres devient inefficace. Le saut de niveau est volontairement présent comme faux-ami : il se discute en qualité web, mais ne doit pas masquer les erreurs de sémantique.

Indices ciblés par cas :

  • Faux titre : « Comprendre le RGAA » est visuellement présenté comme un titre, mais codé avec un paragraphe.
  • Titre détourné : « Publication urgente avant vendredi » est codé en h3 alors qu'il s'agit d'une mise en valeur éditoriale.
  • Faux-ami : le passage de h2 à h4 dans la rubrique Ressources n'est pas l'erreur principale RGAA, même s'il dégrade la qualité du plan.
  • Bonnes pratiques déjà présentes : les accès rapides, le fil d'Ariane et les zones principales ne compensent pas les titres mal structurés.

Identifier les vrais titres, vérifier leur sémantique, repérer les titres utilisés pour la présentation et qualifier les sauts de niveau avec nuance.

Messages de correction ciblés :

  • Faux titre : remplacer le paragraphe stylé par un vrai titre de rubrique adapté au niveau attendu.
  • Titre détourné : remplacer le h3 de mise en valeur par un paragraphe, éventuellement avec strong et une classe CSS.
  • Saut de niveau : harmoniser les niveaux pour améliorer la qualité du plan, sans en faire la non-conformité principale si la hiérarchie reste compréhensible.

Guide du RGAA

Comprendre le RGAA

Le texte ci-dessus est visuellement présenté comme un titre, mais il reste un simple paragraphe dans le code. Un outil de plan de titres ne le proposera pas dans la navigation.

Le RGAA aide les équipes à vérifier qu'un service numérique reste utilisable par le plus grand nombre. Cette introduction devrait être rattachée à une vraie rubrique structurée.

Publication urgente avant vendredi

Cette phrase est une mise en valeur éditoriale, pas un vrai titre de rubrique. La balise de titre sert ici uniquement à obtenir un rendu plus visible.

La correction attendue consiste à utiliser un paragraphe, avec une mise en évidence si nécessaire, puis à réserver les titres aux vraies sections de contenu.

Ressources

Guides pratiques

Le saut de niveau entre le titre Ressources et ce sous-titre sert de faux-ami à discuter pendant la restitution. Il peut gêner la qualité du plan, mais il ne doit pas être confondu avec les deux erreurs principales.

Repères déjà présents

Le gabarit contient des accès rapides, un en-tête, une navigation, un contenu principal et un pied de page. Ces repères sont utiles pour la navigation, mais ils ne corrigent pas les titres mal balisés dans le contenu.
