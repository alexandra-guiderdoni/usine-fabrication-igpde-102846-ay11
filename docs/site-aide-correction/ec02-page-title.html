2. Résultats de recherche RGAA

Aide à la correction

Regarder l'onglet du navigateur, le title HTML et le résultat WAVE. La page affiche déjà la requête, le tri, la page courante et le nombre de résultats : ces informations doivent aussi guider le titre.

L'utilisateur ne sait pas quelle page ou quel état est ouvert, ce qui gêne la navigation entre onglets, historique et résultats. Sur une page de recherche, le titre doit reprendre la requête et la pagination utiles.

Les trois points à vérifier sont :

  • Titre générique : la version à auditer affiche un titre de type « Sans titre » dans l'onglet.
  • Contexte de recherche : la page visible indique la requête « RGAA », la page 2 sur 3 et le tri, mais ces informations ne sont pas reprises dans le titre.
  • Ordre de lecture : l'information spécifique doit arriver avant le nom long du ministère pour rester utile dans un onglet ou un lecteur d'écran.

Rendre le titre unique, ajouter le contexte utile et placer l'information spécifique en premier : requête, page courante, nombre total de pages, puis nom du site.

Corrections attendues :

  • Remplacer le titre générique par un titre unique.
  • Inclure la requête et la pagination utiles.
  • Ordonner le titre du particulier vers le général, par exemple Recherche "RGAA" - Page 2/3 - Ministère de l'Accessibilité numérique.
