#1 Actualité illustrée

Aide à la correction

Niveau 1 - Observer le rôle de chaque image et la structure HTML des liens. Identifiez les 4 cas : image informative, image décorative, lien image pur et lien composite.

Niveau 2 - Appliquer la bonne règle. Une image informative doit porter l'information utile. Une image décorative doit être ignorée. Une image seule dans un lien doit donner l'action ou la destination du lien. Dans un lien composite, si le texte visible suffit, l'icône doit rester silencieuse.

Indices ciblés par cas :

  • Image informative : le schéma de méthodologie d'audit n'a pas d'attribut alt.
  • Image décorative : le séparateur visuel a un alt trop long alors qu'il devrait être ignoré.
  • Lien image courriel : l'enveloppe est le seul contenu du lien. Le test RGAA 6.1.2 attend un intitulé qui donne la fonction et la destination.
  • Lien composite SMS : le texte visible « Envoyer un SMS » donne déjà l'action. Dans le cas RGAA 6.1.3, l'icône n'apporte pas d'information supplémentaire.

Niveau 3 - Corriger chaque cas indépendamment. Les retours doivent isoler le cas fautif pour éviter de mélanger lien image et lien composite.

Messages de correction ciblés :

  • Image informative : le schéma n'a pas d'alternative. Ajouter un alt court qui reprend l'information portée par l'image, sans légende inutile.
  • Image décorative : le séparateur a un alt trop verbeux. Vider l'attribut alt pour qu'il soit ignoré par les technologies d'assistance.
  • Courriel : l'alternative du lien image décrit le visuel au lieu de donner la fonction du lien. Remplacer par un alt d'action, par exemple « Envoyer un courriel au ministère ».
  • SMS : l'icône est dans un lien composite dont le texte donne déjà l'action. Vider l'attribut alt de cette image décorative pour éviter une redondance vocale.

Vérifier l'accessibilité d'une page avant publication

Le ministère publie une méthodologie courte fondée sur le RGAA (Référentiel général d'amélioration de l'accessibilité). Elle s'adresse aux équipes qui contrôlent une page avant publication. La page présente les repères utiles pour vérifier rapidement une ressource.

Le schéma ci-dessous présente les trois étapes proposées aux équipes éditoriales. Il sert à comprendre l'ordre des actions à mener. Chaque étape correspond à un moment concret du travail de publication.

Cette démarche sert de repère pour vérifier une ressource avant publication. Elle aide l'équipe à passer de l'audit à la mise en ligne. Le visuel résume donc une information que le texte seul ne détaille pas entièrement.

La rubrique suivante présente le contact utile pour les questions sur la méthodologie. Un séparateur visuel introduit ce changement de sujet. Il ne porte pas d'information nécessaire à la compréhension du contenu.

Le séparateur visuel marque le passage vers les informations de contact. Il donne simplement un rythme à la lecture de la page. La même information reste compréhensible si ce motif n'est pas restitué.
